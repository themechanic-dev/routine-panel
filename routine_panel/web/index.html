How Routine Panel works

Routine Panel shows every routine and automation of this computer in one place: whether it is running now, how long until it runs next, how its last run went, and how many tokens its last cycle used. It refreshes every 2 seconds and the countdowns tick every second.

It only reads

Nothing here starts, stops or changes a routine. There is no button for that and the panel's server has no request that writes. To change a routine, use the place it belongs to (the Claude app, or systemctl --user for timers).

States

Running
It is running right now; the line under it says for how long. A row lights up for a moment when its routine starts.
Waiting
Its last run went well and it waits for the next one.
Fault
Something is wrong: the last run failed, a run that was due did not happen, a program that should run all the time is down or its heartbeat stopped, or the Claude app is closed (its routines run only while it is open). The reason and the last lines of the log are shown in the row.
Off
Turned off: it will not run until someone turns it on again.
Needs you
The routine is fine but waits for your answer (for example a proposal sent to your phone).

Columns

  • Schedule: when it runs, in words. Claude routines start a few minutes after their time, the same few minutes each time, so the panel shows the usual delay and marks the next run with ≈.
  • Next run: a countdown to the next run, and its time. “After this run” means the next time is set when the running one ends.
  • Last run: when it started, how long it took, and what it said at the end.
  • Tokens · last cycle: the tokens of the last run only, never totals. in is what was sent to Claude and not read from the cache (cache writes included), cache what was read from the cache, out what Claude wrote. “so far” marks a run that is still going. “no Claude” means the routine does not use Claude; “—” for the cache means its log does not record it.

Click a row (or press Enter on it) for its details: where it comes from, the exact numbers and the last lines of its log.

List and Grid

The switch at the top right changes the view. List shows one row per routine, grouped by where it comes from. Grid shows each routine as a tile and fits them all in the window, without scrolling: the panel chooses the number of columns and the size of the text from the window's size and the number of routines, and does it again when a routine is added or the window changes size. Click a tile for its details. The view you choose is remembered.

Where it reads from

  • Timers (Linux): your own systemd timers (unit files in ~/.config/systemd/user and timers made with systemd-run), with their journal. Scheduled tasks (Windows): the tasks of Task Scheduler whose author is you.
  • Claude routines: the Claude app's scheduled tasks and their runs, and Claude Code's transcripts (~/.claude/projects) for the tokens.
  • Always running: programs you name in the settings, with their heartbeat file.

Settings

Optional, in ~/.config/routine-panel/settings.json (on Windows %APPDATA%\RoutinePanel\settings.json); the panel reads them when it opens.

  • "screen": the monitor the window opens on.
  • "token_logs": {"name.service": "~/path/to.log"} for a program that calls Claude itself and writes each call to its log (“asked claude-…: N tokens in, M out”).
  • "processes": programs that run all the time: [{"unit": "name.service", "heartbeat": "~/file", "every_s": 60, "log": "~/file"}].
  • "hidden": ids of rows to leave out (each row's details show its id); "labels": another name or line for a row; "show_system_timers": also the system's own timers.

Phones

The Phone button pairs a phone with the panel: it shows a code that the Routine Panel app on the phone scans once. After that the phone shows the same panel, at home over the home network and away over Tailscale (both the phone and this computer must be in your Tailscale network). A phone only reads, like the window. Each phone has a key of its own: Remove takes it away at once. A code nobody scanned stops working after 10 minutes. Phones connect through Routine Panel's service, which starts when you sign in. It is installed with ./install.sh --phone on Linux, and with the Setup's option “Let my phone see the panel” on Windows.

Theme

Auto follows the system's light or dark style; Light and Dark keep one. The choice is remembered.

The window

The window opens where it was when you closed it: on the same screen, and full screen or maximized if it was. F11 leaves full screen and goes back to it. The first time, it opens as the settings say ("screen" and "window_mode": normal, maximized or fullscreen).
